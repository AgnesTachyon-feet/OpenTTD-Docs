static

Create a news message for everybody, or for one company.

Parameters
typeThe type of the news.
textThe text message to show (can be either a raw string, or a GSText object).
companyThe company, or COMPANY_INVALID for all companies.
ref_typeType of referred game element.
referenceThe referenced game element of ref_type.
  • For NR_NONE this parameter is ignored.
  • For NR_TILE this parameter should be a valid location (GSMap::IsValidTile).
  • For NR_STATION this parameter should be a valid stationID (GSStation::IsValidStation).
  • For NR_INDUSTRY this parameter should be a valid industryID (GSIndustry::IsValidIndustry).
  • For NR_TOWN this parameter should be a valid townID (GSTown::IsValidTown).
Returns
True if the action succeeded.
Precondition
type must be #NewsType::Economy, #NewsType::Subsidies, or #NewsType::General.
text != null.
company == COMPANY_INVALID || ResolveCompanyID(company) != COMPANY_INVALID.
The reference condition must be fulfilled.
GSCompanyMode::IsDeity().
