enum class StringValidationSetting : uint8_t
strong

Settings for the string validation.

Enumerator
ReplaceWithQuestionMark 

Replace the unknown/bad bits with question marks.

AllowNewline 

Allow newlines; replaces '\r
' with '
' during processing.

AllowControlCode 

Allow the special control codes.

ReplaceTabCrNlWithSpace 

Replace tabs ('\t'), carriage returns ('\r') and newlines ('
') with spaces.

When StringValidationSetting::AllowNewline is set, a '
' or '\r
' combination are not replaced with a space. A lone '\r' is replaced with a space. When StringValidationSetting::ReplaceWithQuestionMark is set, this replacement runs first.
